**original_problem_statement:**
The user wants to build a comprehensive mobile application for their Auto Repair Shop Management System, named Ohio Airbag Light Reset.

**PRODUCT REQUIREMENTS (Based on initial request and subsequent user feedback):**
- **Roles:** Admin and Technician, with distinct permissions. Admins have full access to financial data and user management. Technicians have limited access, focusing on work orders without seeing financial totals on reports.
- **Core Workflow:**
    1.  **Order Creation:** Admins can create orders by assigning a client, services, and a technician, but without a VIN.
    2.  **Order Details:** Technicians view assigned orders, which include a clickable client address (opens Google Maps) and phone number.
    3.  **VIN Scanning:** The technician must scan the vehicle's VIN on-site to start the work. The app must handle scanning errors gracefully.
    4.  **Work Execution:** Update order status (Assigned, Initiated, Pending, Completed).
    5.  **Completion & Notification:** When an order is marked Terminado (Completed), a WhatsApp message is automatically sent via Twilio to a predefined list of numbers (owner, admin, techs). The message includes vehicle details (make, partial VIN) and the assigned technician.
- **Admin Features:**
    - **Web-based Office Panel:** A professional, responsive dashboard for desktop/laptop use, allowing admins/secretaries to manage the business, run reports, and view financial status.
    - **PDF Reports:**
        - **Daily Financial Report:** A printable PDF summarizing daily revenue, broken down by payment method (Zelle, cash, check), and outstanding debt.
        - **Credit Account Report:** A printable PDF showing outstanding balances grouped by client.
    - **Client/User Management:** Manage clients, users, and workshop settings (like the workshop name).
- **General Features:**
    - **PDF Invoices:** Generate a professional PDF invoice for any work order, which can be shared.
    - **Credit Accounts:** Ability to mark clients as having a credit account, which alters the payment workflow for technicians.

**User's preferred language**: Spanish. The next agent MUST respond in Spanish.
