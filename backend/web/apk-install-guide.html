⚠ Importante (según Colorlight):
  • El A40 corre Android 9.0 simplificado — algunos componentes del sistema no existen.
  • Colorlight no garantiza operación 7×24 con APKs de terceros. Nuestro APK ya incluye watchdog, reinicio nocturno y auto-recuperación de crash para mitigar esto.
  • Nunca llenar el almacenamiento del A40. Nuestro APK limita la caché automáticamente.
  • El APK no debe modificar la hora ni la zona horaria del sistema, eso rompe la validación HTTPS.

2. Método 1 — PlayerMaster Recomendado

Es el flujo oficial de Colorlight para instalar APKs custom en el A40. Permite distribuir el reproductor a varios A40 al mismo tiempo.

1
Descargar el APK

Click en ⬇ Descargar APK v2.2.0 arriba. Guarda mediaview-player-v2.2.0.apk en una carpeta accesible.

2
Abrir PlayerMaster y descubrir el A40

1. Abre PlayerMaster en tu PC.
2. Verifica que tu A40 esté encendido y conectado a la misma red Wi-Fi.
3. En la pestaña Terminal → deberías ver tu A40 listado por su Serial Number (ej. CLCA40002896).

3
Entrar al modo avanzado

1. Selecciona tu A40 en la lista de Terminales.
2. Click en Advanced (o Avanzado).
3. Introduce la contraseña: 168.

4
Instalar el APK personalizado

1. En el menú avanzado, busca Custom APK Installation (o Application Management → Install APK).
2. Click Browse → selecciona mediaview-player-v2.2.0.apk.
3. Click Install / Send to Terminal.
4. PlayerMaster transfiere el archivo y el A40 lo instala. Demora ~1–2 minutos.

5
Definir MediAd View Player como Launcher

En el mismo menú Advanced:

1. Busca Default Launcher (o Home Application / Boot App).
2. Selecciona MediAd View Player de la lista.
3. Apply y Reboot el A40.

🔁 Tras el reinicio, el A40 ya no muestra la app nativa de Colorlight — arranca directamente en MediAd View Player.
Si PlayerMaster no tiene la opción "Custom APK Installation": es porque tu firmware del A40 todavía no fue personalizado por Colorlight. Hay 2 alternativas: (a) escribir a Colorlight pidiendo el firmware con esa opción habilitada (suele tardar ~3 días); o (b) usar el Método 2 (ADB) que funciona sobre el firmware de fábrica porque el A40 ya viene con ADB habilitado por defecto.

3. Método 2 — ADB sobre Wi-Fi Funciona en el firmware de fábrica

El A40 viene con ADB habilitado por defecto en el puerto 5555. Este método funciona sin tocar firmware.

3.1 Encontrar la IP del A40

  1. En el A40 ve a Settings → Network y anota la IP (ej. 192.168.1.50).
  2. O en PlayerMaster, click sobre el A40 → la IP aparece en sus propiedades.

3.2 Instalar ADB en tu PC

  • Windows / Mac: Descargar platform-tools de Android.
  • Mac (Homebrew): brew install android-platform-tools
  • Linux: sudo apt install adb

3.3 Conectar e instalar

Abre Terminal (Mac/Linux) o PowerShell (Windows) y ejecuta:

# 1. Conectar al A40
adb connect 192.168.1.50:5555

# 2. Verificar conexión
adb devices
# debe aparecer: 192.168.1.50:5555  device

# 3. Instalar el APK
adb install -r mediaview-player-v2.2.0.apk

# 4. Configurar MediAd View como launcher por defecto (auto-arranque)
adb shell cmd package set-home-activity com.mediaview.player/.MainActivity

# 5. Lanzar la app por primera vez
adb shell am start -n com.mediaview.player/.MainActivity

# 6. (Opcional) Pasar la URL del servidor y Screen ID por intent extras
adb shell am start -n com.mediaview.player/.MainActivity \
  --es server_url "https://api.mediadview.com" \
  --es screen_id "TU_SCREEN_ID"

# 7. Desactivar timeout de pantalla del sistema
adb shell settings put system screen_off_timeout 2147483647
adb shell settings put secure screensaver_enabled 0
Después del paso 4 el A40 ya arranca automáticamente en MediAd View al encender. No requiere PlayerMaster.

4. Método 3 — USB con pendrive Sin PC

Si no tienes PlayerMaster ni ADB a mano y solo tienes el A40 + un mando + un pendrive.

  1. Descarga mediaview-player-v2.2.0.apk en un pendrive USB FAT32.
  2. Conecta el pendrive al puerto USB del A40.
  3. En el A40, abre File Manager → USB, busca el APK y dale Install.
  4. Cuando termine, abre la app desde el menú de aplicaciones.
  5. Para hacerlo launcher predeterminado, presiona el botón HOME del mando — Android te preguntará qué launcher usar → elige MediAd View Player + Always.

5. Emparejar el reproductor con MediAd View

Una vez instalado, el APK arranca en la pantalla de activación y te muestra un código de 6 dígitos.

1
Anotar el código que aparece en la pantalla LED

Ejemplo: 428-915

2
En MediAd View → Pantallas → Editar pantalla

Buscar la sección Reproductor (APK) → ingresa el código → click Vincular.

3
Listo

El A40 detecta la activación en menos de 30 segundos y empieza a reproducir el contenido configurado para esa pantalla.

Menú oculto de configuración (en el A40)

Con un teclado USB o el mando IR conectado al A40:

  • Presionar Menu 5 veces seguidas (menos de 3 segundos).
  • O mantener OK / Enter durante 5 segundos.

Se abre un diálogo donde puedes cambiar:

  • URL del servidor — para apuntar a otro servidor de MediAd View.
  • Screen ID — para vincular manualmente sin código.
  • Reset completo — borra todo y vuelve a la pantalla de activación.

6. Auto-arranque al encender el A40

El APK ya viene con todos los BOOT_COMPLETED, HOME launcher, WakeLock, watchdog cada 5 min y reinicio nocturno a las 3 AM listos. Solo hay que asegurarse que esté seleccionado como Launcher predeterminado:

7. Buenas prácticas y mantenimiento

  • Reinicio automático: el APK se reinicia internamente todos los días a las 3:00 AM para liberar memoria. Adicionalmente puedes programar un reinicio físico del A40 cada 3-7 días (recomendado por Colorlight).
  • Horario Sleep / Wake automático: ya implementado en MediAd View. Configurable desde Admin Panel → LED Cloud → Editar pantalla → Schedule. El backend evalúa el horario cada minuto y manda comando al A40.
  • Actualizaciones del APK: cuando subamos una versión nueva al servidor, el reproductor la detecta en el próximo heartbeat (cada 5 min) y se actualiza solo. No requiere tu intervención.
  • Diagnóstico: presiona la tecla I en un teclado USB para mostrar el HUD con FPS, conexión, ID, caché.
  • Almacenamiento: el caché máximo en disco está limitado a 2 GB. Cuando se llena, se borran los archivos más antiguos primero.

8. Solución de problemas comunes

ProblemaSolución
PlayerMaster no detecta el A40Verifica que ambos estén en la misma red Wi-Fi. Reinicia el A40. Comprueba que el firewall del PC no bloquee el puerto 6000.
ADB dice unable to connect1) adb kill-server && adb start-server
2) Verifica IP correcta
3) Confirma que el A40 tenga ADB habilitado (lo está por defecto)
APK se instala pero no se abre al bootNo está configurado como launcher por defecto. Ejecuta el comando del paso 4 o cambialo desde PlayerMaster.
Pantalla queda en negro o se duermeEjecuta el paso 7 del ADB (deshabilitar timeout). El APK ya activa WakeLock pero el sistema puede sobreescribirlo en algunos firmwares.
Video se corta o pixelaRecomienda recodificar a H.264 baseline @ 1080p 30fps. El A40 no soporta H.265.
"Sin conexión de red"El A40 perdió Wi-Fi. El APK reintenta automáticamente cada 5–60 seg con backoff exponencial.
Menú oculto no apareceUsar teclado USB físico — los mandos IR no siempre mandan el código Menu. Como alternativa: mantener OK presionado 5 segundos.
Quiero desinstalar el APK y volver al firmware Colorlightadb uninstall com.mediaview.player y luego en Settings → Default Launcher → seleccionar la app nativa de Colorlight.
