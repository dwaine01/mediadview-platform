Instalación en Google TV / Android TV

1

Habilita Developer options (Settings → About → Build × 7 clicks)

2

Activa Install unknown apps en Developer options

3

Instala la app Downloader desde Play Store

4

En Downloader escribe: mediadview.com/apk → Go → Install

5

Abre MediaView Player → verás un código estilo MV7K2N

6

En panel.mediadview.com → Devices → Pair → introduce el código → asignar Screen

7

La TV cambia automáticamente al contenido programado 🎉
